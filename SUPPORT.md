# Support

Use the channel that matches the kind of help you need.

| Need                                              | Use                                                                    |
| ------------------------------------------------- | ---------------------------------------------------------------------- |
| Broken page, docs regression, or non-security bug | GitHub Issues                                                          |
| New docs, site, or contributor-workflow idea      | GitHub Issues                                                          |
| Security vulnerability                            | Private reporting path in [SECURITY.md](SECURITY.md)                   |
| Conduct concern                                   | Private maintainer contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribution workflow question                    | [Docs contributor guide](src/content/docs/contributing.mdx)            |

## Routing notes

- Use Issues for broken routes, rendering bugs, missing pages, accessibility problems, and tracked docs work.
- Use Pull Requests when you already have a concrete patch.
- Use the private channel described in [SECURITY.md](SECURITY.md) for vulnerabilities.
- Use the private contact path in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.
- Use the shared RustUse contribution policy in [RustUse/.github CONTRIBUTING.md](https://github.com/RustUse/.github/blob/main/CONTRIBUTING.md) for organization-wide expectations.

The canonical support surface for this repository is GitHub.
