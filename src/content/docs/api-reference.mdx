RustUse.org is the primary API documentation surface for the currently supported crates.

Most current public crates are published and have live registry links. When a local crate name conflicts with an already-published package identity, RustUse keeps a workspace-scoped API route instead of linking users to the wrong external package.

<MascotImportant title="Registry links follow live package identity">
  <p>
    Publish live `crates.io` and `docs.rs` links only when the external package
    identity resolves to the intended RustUse crate. If a package name is
    blocked or collides with another published crate, prefer a workspace-scoped
    RustUse route until that identity is resolved.
  </p>
</MascotImportant>

## How RustUse.org relates to crates.io and docs.rs

- RustUse.org hosts the curated guides, set pages, crate overviews, and generated API docs.
- `crates.io` is the package registry and should point each published crate's `documentation` field at the stable RustUse API URL.
- `docs.rs` may still build generated docs automatically after publication, but it is a fallback reference rather than the canonical destination.
- Published crates should expose live registry links only when the package identity resolves to the intended RustUse crate.
- When package names collide, prefer a workspace-scoped RustUse route until the published identity is resolved.
- Do not scrape or mirror `docs.rs` HTML into this site.

## Recommended Cargo.toml metadata

```toml
[package]
name = "use-geometry"
description = "Primitive geometry utilities for Rust."
repository = "https://github.com/RustUse/use-geometry"
homepage = "https://rustuse.org"
documentation = "https://rustuse.org/api/use-geometry"
license = "MIT OR Apache-2.0"
readme = "README.md"
keywords = ["geometry", "math", "utility"]
categories = ["mathematics"]
```

- Use `homepage` for the RustUse project site.
- Use `documentation` for the stable RustUse API path once it is live for a published crate.
- Use `repository` for GitHub.
- Keep `README.md` ready for the crates.io package page.
- Keep scaffolded or blocked crates on RustUse-hosted API docs until the external registry pages are confirmed correct for that crate identity.

- Validate the rustdoc JSON `format_version` before parsing it in Rust or Node.
- Do not depend on rustdoc JSON for the first version of the site.
