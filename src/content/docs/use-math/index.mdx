## Overview

The current `use-math` set surfaces {getPublicCratesBySet('use-math').length}
public crate tracks: the `use-math` facade plus its focused crates. The facade
stays intentionally thin: it re-exports focused crates behind explicit
features, preserves crate-shaped namespace modules, and keeps the shared
`prelude` limited to the ergonomic layer that belongs at the facade boundary.

Use this page as the combined entry point for the set overview and the `use-math` facade crate itself.

## Facade role

Use `use-math` when you want a curated entry point instead of depending on focused crates one by one.

- Feature-flagged root re-exports from the focused math crates in this workspace
- Matching nested modules for crate-shaped namespacing
- A `prelude` module for common imports
- One dependency and one import surface for the current math set

## Current focused families

- Arithmetic and number primitives: `use-arithmetic`, `use-integer`, `use-number`, `use-rational`, `use-real`, `use-complex`
- Algebra, logic, and set helpers: `use-algebra`, `use-logic`, `use-set`, `use-modular`, `use-prime`
- Sequences and counting: `use-combinatorics`, `use-catalan`, `use-collatz`, `use-series`, `use-geode`
- Linear and reusable primitives: `use-vector`, `use-matrix`, `use-linear`, `use-eigen`
- Equation and approximation helpers: `use-polynomial`, `use-equation`, `use-numerical`, `use-calculus`
- Probability and descriptive summaries: `use-probability`, `use-statistics`, `use-trigonometry`

## Design direction

The facade should stay thin. It should expose high-value conveniences, keep feature flags explicit, and avoid turning the set into a mandatory all-in-one dependency.

Shared conventions and helper types that support the facade belong here only when they make the public surface clearer. They should not become a separate public crate.

## Composition

Reach for the focused crates when you want the narrowest dependency surface for a specific domain. Reach for `use-math` when one dependency, root re-exports, and a shared `prelude` are the clearer integration shape. Reach for the sibling `use-geometry` set when you need geometry primitives.

## Example API sketch

The sketch below is illustrative only. Names and signatures are not final.

```rust
use use_math::prelude::*;

assert_eq!(factorial(5)?, 120);
assert_eq!(combinations(5, 2)?, 10);
# Ok::<(), use_math::combinatorics::CombinatoricsError>(())
```
