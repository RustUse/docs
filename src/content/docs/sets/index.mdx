RustUse currently organizes its initial docs around two early sets so the launch surface stays easy to understand and adopt.

## Sets

A set is the top-level RustUse domain. Today that means `use-math` and `use-geometry`.

Sets define the shared problem space, naming conventions, and the boundary between the facade crate and the focused crates inside the set. Some early sets, such as `use-geometry`, currently consist of a single focused crate.

## Current public crate tracks

RustUse currently exposes four public crate tracks across the two active sets:

- [use-combinatorics](/use-math/use-combinatorics/) - discrete-math crate for counting, combinations, permutations, and finite-structure helpers.
- [use-collatz](/use-math/use-collatz/) - bounded Collatz trajectory helpers and parity summaries.
- [use-math](/use-math/) - facade crate with feature-flagged re-exports and a `prelude` module.
- [use-geometry](/use-geometry/) - 2D geometry primitives and common measurement helpers.

## Current model in practice

- `use-combinatorics` and `use-collatz` provide focused tracks inside the `use-math` set.
- `use-geometry` currently anchors its own focused geometry set.
- `use-math` provides the curated facade layer for the math set.

## Current sets

RustUse is currently focused on two early sets:

- [use-math](/sets/use-math/) - currently represented by `use-math`, `use-combinatorics`, and `use-collatz`.
- [use-geometry](/sets/use-geometry/) - currently represented by the focused `use-geometry` crate.

## Status

Initial scope. The current focus is stabilizing `use-math`, `use-geometry`, `use-combinatorics`, and `use-collatz` across the first two public sets.
