RustUse organizes public navigation around published sets so facade crates, focused crates, and generated RustDocs routes stay easy to navigate as the ecosystem grows.

## Sets

A set is the top-level RustUse domain. Sets define the shared problem space, naming conventions, and the boundary between a facade crate and the focused crates inside the set.

The menu now includes every published set facade tracked by the unified `rustuse` crate. The shared catalog also includes the current focused crates from each scanned workspace. Curated set guides and generated workspace Rustdocs still roll out incrementally.

## Current model in practice

- Every scanned workspace now contributes its current crate inventory to the shared catalog and sidebar.
- `use-math` and `use-geometry` currently go further than the other sets with curated pages and generated workspace Rustdocs.
- The set pages, crate catalog, and sidebar entries are generated from shared metadata so counts, routes, and statuses stay aligned as more sets are expanded.
