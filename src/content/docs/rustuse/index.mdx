`rustuse` is the planned crates.io umbrella crate for the RustUse ecosystem. It will publish all `use-*` sets under one registry entry, with each set available as a named feature flag. You add the set you want rather than listing individual crates.

## Purpose

The goal of `rustuse` is to keep adoption simple. A single dependency declaration selects the set you need. Everything inside that set is available through the feature gate — you do not need to know which focused crates compose it.

## Planned usage

When `rustuse` is published, adding the `use-math` set to a project will look like this:

```toml
[dependencies]
rustuse = { version = "0.1", features = ["use-math"] }
```

That single line brings in the `use-math` set, including its facade crate and the focused crates it composes.

<MascotTip title="Add sets, not individual crates">

## Planned feature flags

Each RustUse set maps to one feature flag in `rustuse`:

| Feature flag | Set |
| --- | --- |
| `use-math` | The initial math set: `use-math`, `use-geometry`, `use-combinatorics`. |

Feature flags will be additive. You can enable more than one set in a single `rustuse` dependency if a project spans multiple domains.

## Repository

The `rustuse` crate will live in its own repository at [github.com/RustUse/rustuse](https://github.com/RustUse/rustuse), separate from the individual set workspaces.
