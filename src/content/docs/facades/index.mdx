## Facades

A facade is the top-level RustUse domain. Facades define the shared problem space, naming conventions, and the boundary between a facade crate and the focused crates behind it.

## RustUse facades

<ul>
  {facades.map((set) => {
    const crateCount = getPublicCratesByFacade(set.name).length;

    return (
      <li>
        <a href={set.setPath}>{set.name}</a> - {set.description}{' '}
        {crateCount > 0
          ? crateCount > 1
            ? `${crateCount} public crate tracks are cataloged today.`
            : 'Facade crate page is live now; focused crate pages are queued for a later docs wave.'
          : 'Detailed crate pages are queued for a later docs wave.'}
      </li>
    );

})}

</ul>
