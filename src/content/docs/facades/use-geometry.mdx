## Purpose

This facade keeps pure geometry primitives, notation, relations, constructions, and decomposition crates separate from the broader `use-math` surface while preserving a thin geometry facade for one-dependency use cases.

The facade is intentionally broad inside pure geometry. Many child crates start with primitive value types, metadata records, descriptors, or small direct helpers so algorithms can grow inside focused crates without turning the facade crate into an implementation crate.

## Install

Choose the facade when you want one dependency for the current geometry surface:

```toml
[dependencies]
use-geometry = "0.2.1"
```

Choose child crates directly when you want a narrower dependency surface:

```toml
[dependencies]
use-point = "0.0.6"
use-line = "0.2.1"
use-geometric-complex = "0.0.6"
```

The facade can also be narrowed with feature flags:

```toml
[dependencies]
use-geometry = { version = "0.2.1", default-features = false, features = ["point", "line", "triangle"] }
```

## Choose an entry point

| Need                                            | Start with                   | Why                                                                                          |
| ----------------------------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------- |
| One dependency for several geometry families    | `use-geometry`               | The facade reexports child crates behind feature flags and gives a shared namespace.         |
| Points, lines, shapes, or notation in isolation | The focused child crate      | Direct crates keep package scope and docs narrow.                                            |
| Vector math without geometry-specific types     | `use-vector` from `use-math` | Reusable vector primitives belong to the math facade and are consumed by geometry crates.    |
| Geode-array recurrence helpers                  | `use-geode` from `use-math`  | Geode helpers are mathematical sequence and counting utilities, not spatial geometry crates. |

## Current boundaries

- The facade crate reexports child crates and exposes namespace modules; implementation belongs in focused child crates.
- `use-line` is the published package for line primitives, with the Rust library name `use_line`.
- `use-geometric-complex` is the published package for geometric complex primitives, with the Rust library name `use_complex`.
- `use-vector` remains in the sibling `use-math` workspace and is used by child crates that need vector primitives.
- `use-geode` remains in `use-math` and is not part of the geometry facade.

## Release alignment

The `use-geometry 0.2.1` facade release aligns the public docs with the geometry crates that consume `use-vector 0.0.7` from the sibling math facade. Most child crates remain on their `0.0.6` line, while compatibility updates include `use-point 0.1.0`, `use-plane 0.1.0`, `use-orientation 0.1.0`, `use-ray 0.1.0`, and `use-line 0.2.1`.
