## How to read the catalog

- `use-math` is the facade entry point for the broader math set, which now includes focused crates for arithmetic, algebra, sequences, linear primitives, numerical helpers, and validated numeric types.
- `use-geometry` is the facade entry point for the broader geometry set, which now includes focused child crates for foundations, primitives, transformations, relations, curves, regions, polytopes, configurations, complexes, and folding or decomposition work.
- `Published` means the crate has live registry links plus canonical RustUse API docs.
- `Scaffolded` means RustUse-hosted docs are available, but the external package identity is still staged or blocked.
- `Planned` is reserved for crates that are visible in docs before they become part of the supported public surface.
