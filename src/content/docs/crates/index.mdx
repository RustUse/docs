## How to read the catalog

- The shared catalog now includes the current crate inventory from the scanned RustUse workspaces, not just the facade crates.
- `use-math` and `use-geometry` still go further than the other facades: they have curated guides and generated RustUse RustDocs for their current child crates.
- Many other crates currently appear here with generated overview pages plus live package links while RustUse-hosted RustDocs routes are added incrementally.
- `Published` means the crate has live registry links and is part of the supported public docs surface. Many published crates also have canonical RustUse RustDocs already.
- `Scaffolded` means RustUse-hosted docs are available, but the external package identity is still staged or blocked.
- `Planned` is reserved for crates that are visible in docs before they become part of the supported public surface.
