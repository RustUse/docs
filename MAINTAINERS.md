# RustUse Docs Maintainers

This document lists the maintainers for the RustUse docs repository.

## Current maintainers

| GitHub                                         | Responsibilities                                                                                     |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [@cloudbranch](https://github.com/cloudbranch) | Review pull requests, maintain release and deployment workflows, and steward contributor-facing docs |

## Maintainer responsibilities

Maintainers are expected to:

- review pull requests in a timely way
- keep required checks and branch protection rules aligned
- preserve Conventional Commit titles when merging so release automation stays accurate
- verify release notes and published artifacts when cutting releases
- keep onboarding, governance, and deployment documentation accurate

If the maintainer roster changes, update this file, `.github/CODEOWNERS`, and any linked governance references together.
